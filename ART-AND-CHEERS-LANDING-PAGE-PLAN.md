# Art and Cheers Landing Page – Plan

Inspired by [Works in Progress](https://worksinprogress.co/). This document covers: (1) Works in Progress sections/components and styles, (2) Content plan for Art and Cheers, (3) Build plan, (4) Questions for clarity.

## Part 1: Works in Progress – Sections & Components

### 1.1 Header
- **Logo:** “Works In Progress” in two lines + small abstract icon (gears / “W” in circle), top left.
- **Main nav:** “Issues” with dropdown (⌄), vertical bar separator.
- **Utility nav (right):** Podcast, Newsletter, Substack, **Subscribe** (primary CTA button).
- **Hamburger:** Three-line icon for mobile / extended menu (Films, Books in Progress, About, Authors, Pitch us, Archive, Subscribe).
- **Divider:** Thin horizontal line under header.

### 1.2 Hero / Spotlight Section
- **Large feature image:** Full-width, editorial/artistic (e.g. drywall grid, tiger embroidery).
- **Text overlay box:** Positioned bottom-left on image.
  - **Title:** Large, bold serif (e.g. “The wonder of modern drywall”).
  - **Byline:** “Words by [Author]” in smaller sans-serif.
  - **Excerpt:** Short paragraph.
  - **Category/tag:** Underlined link (e.g. “Sandwiches”, “Anglosphere”).
  - **CTA:** “Read more →” or “Read now”.
- **Optional labels:** “Spotlight”, “Issue 22” (small tags on image).

### 1.3 Print / Product CTA Section
- **Layout:** Two columns – image left, copy + CTA right.
- **Left:** Tilted magazine/product image.
- **Right:**
  - **Headline:** e.g. “Get the print magazine”.
  - **Offer:** Price and frequency (e.g. “Subscribe for $100 to receive six beautiful issues per year”).
  - **Urgency:** “Subscribe today to receive a copy of Issue 22.”
  - **Button:** Secondary style (e.g. yellow/beige, rounded).

### 1.4 Article Grid
- **Layout:** Grid (e.g. one large image card + several text-focused cards).
- **Image card (e.g. left):**
  - Tags: “Spotlight”, “Issue 22”.
  - Featured image.
  - Title, author, excerpt, “Read more →”, category.
- **Text cards (e.g. right):**
  - Title (serif, bold).
  - “Words by [Author]”.
  - Short summary.
  - “Read more →”.
  - Category/tag (underlined).

### 1.5 Article List / Sidebar (optional)
- Vertical list: “[Author] on [topic]” or “[Author] on [title]”.
- Simple, scannable, sans-serif; each row clickable.

### 1.6 Footer
- Links: Subscribe, Print magazine, Manage subscription, Privacy, Cookies, Ethics & standards.
- Copyright: “Works in Progress Magazine © 2026”.
- Credit: “Designed by And–Now”.
- Contact: worksinprogress@stripe.com, wip-print@stripe.com.

## Part 2: Works in Progress – Styles

### 2.1 Color
- **Background:** Off-white / warm beige/cream (e.g. `#F9F5F0`).
- **Text:** Dark charcoal/black (e.g. `#333333`, `#1a1a1a`).
- **Primary CTA:** Black button, white text (header Subscribe).
- **Secondary CTA:** Yellow/gold/beige button, dark text (print Subscribe).
- **Overlay (hero):** Teal-green or deep blue (e.g. `#33418C`), white text.
- **Tags:** Black “Spotlight”, yellow “Issue 22”; optional orange accent.
- **Links:** Underlined for categories/tags.

### 2.2 Typography
- **Headings/titles:** Serif, bold (e.g. Georgia, Playfair Display, Lora).
- **Body / bylines / nav:** Sans-serif (e.g. Open Sans, Lato, system-ui).
- **Hierarchy:** Large serif for hero title; smaller sans for author, excerpt, tags.
- **CTA text:** “Read more →” with arrow in sans-serif.

### 2.3 Layout & Spacing
- **Whitespace:** Generous padding and margins; breathable, editorial.
- **Content width:** Constrained max-width, centered or aligned to grid.
- **Dividers:** Thin horizontal lines between header areas and sections.
- **Grid:** Clear columns for hero vs grid vs list; responsive breakpoints.

### 2.4 Imagery
- **Hero:** High-quality, full-bleed; artistic/illustrative or strong photography.
- **Overlay:** Solid or semi-transparent box; text never lost on image.
- **Cards:** Consistent aspect ratios; illustrations or photos.

### 2.5 Interactive
- **Buttons:** Solid fill, clear hover state.
- **Links:** Underline on categories/tags; “Read more →” as link.
- **Nav:** Dropdown for “Issues”; hamburger for full menu on small screens.

## Part 4: Build Plan

### 4.1 Tech Stack (suggested)
- **Option A – Simple:** HTML, CSS, JS (no build step). Good for a single landing page and fast launch.
- **Option B – React/Next:** If you want components, CMS later, or multiple pages.
- **Option C – Astro:** Static, fast, optional islands (React/Vue) only where needed.

Recommendation: Start with **HTML/CSS/JS** or **Astro** for a one-page site; move to Next/React if you add blog, shop, or auth.

### 4.2 Structure
1. **Setup:** Repo, folder structure (`/assets/images`, `/css`, `/js`), optional design tokens (colors, fonts).
2. **Design tokens:** Colors and typography from Part 2, adapted to Art and Cheers palette.
3. **Header:** Logo, nav, CTA, hamburger, sticky behavior.
4. **Hero:** Full-width image, overlay box, responsive (stack on small screens).
5. **CTA section:** Two-column layout; responsive to single column.
6. **Grid:** CSS Grid or Flexbox; 1 large + N small cards; responsive (e.g. 1 col → 2 → 3).
7. **Footer:** Links, social, copyright.
8. **Polish:** Hover states, focus styles, basic animations (e.g. fade-in), lazy loading for images.
9. **Content:** Swap placeholders for real copy and images from Instagram/assets.
10. **Deploy:** Vercel, Netlify, or GitHub Pages.

### 4.3 Phases
- **Phase 1 (MVP):** Header, hero, one CTA section, one grid row, footer. Single page, no CMS.
- **Phase 2:** Full grid, list/sidebar if needed, responsive refinement, performance (images, fonts).
- **Phase 3:** Optional: CMS (e.g. Sanity, Contentful) for “Spotlight” and grid items; or link to Instagram via API/widget.

### 4.4 File Checklist (example)
- `index.html` – single page, semantic sections.
- `css/styles.css` or `css/global.css` – tokens, layout, components.
- `js/main.js` – hamburger, smooth scroll, optional lightbox.
- `assets/images/` – hero, grid images, logo, favicon.

4. **Functionality**
   - Any signup (e.g. Mailchimp, ConvertKit) or “Book” link (Calendly, typeform) to wire into the CTA buttons?

5. **Scope**
   - Launch goal: one scrolling landing page only, or “landing + one level of inner pages” (e.g. About, Contact)?

Once you answer these, the content plan (Part 3) and build plan (Part 4) can be updated and we can start with a concrete first version of the landing page (e.g. copy-paste ready sections and styles).
